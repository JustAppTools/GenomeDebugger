# Representative-user validation protocol

This protocol is ready for use; no participant sessions or results are claimed.

Recruit consenting people from both audiences: readers who did not prepare the files, and analysts who produce annotation outputs. Use the bundled synthetic examples or reviewed public reference fixtures, not personal genetic records.

Ask each person to:

1. Explain what the website does and what it needs, without reading a manual.
2. Choose the right entry path for an example, two supplied files, and a public variant.
3. Explain where assembly, accession, reference letters, and tool/source versions come from. Record whether they guess a value.
4. Preview a supported file pair, identify a deliberately missing field, and complete a valid comparison.
5. Identify the principal changed prediction and explain what supports a causal finding.
6. Distinguish local-context identity from external reference verification, and a possible explanation from a demonstrated synthetic replay.
7. Save/resume a local draft, find a named comparison, archive/restore it, and obtain a readable report.
8. Repeat the essential reading/navigation tasks with keyboard-only input and the participant's normal assistive technology where relevant.

Before the sessions, set measurable acceptance criteria for task completion, assistance required, incorrect interpretations, and time to a first useful comparison. In particular, require participants to state both the main result and its uncertainty. Record observations and revise the flow where people stop or guess; visual preference is not sufficient evidence of usability.

The in-app Help checklist offers four comprehension responses, task role, and optional minutes spent. It stays in memory until the participant explicitly downloads it. It contains no variant, file, report, account, or personal identifiers and does not automatically contact a service. Use a separately agreed feedback channel if participants choose to share their checklist.

Automated keyboard, layout, and axe checks are engineering evidence, not a substitute for observing people or a declaration of complete WCAG conformance.
